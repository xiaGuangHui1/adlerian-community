# 服务器部署方案总结

> 整理自与 Claude 的服务器讨论，2026-09-09

## 一、当前部署现状（国外）

| 组件 | 平台 | 位置 | 费用 |
|---|---|---|---|
| 后端 | Railway | 美国 | 试用金，低流量暂未收费 |
| 数据库 | Supabase | AWS（国外） | 免费档 500MB |
| 前端 | Vercel / Nginx | 国外 | 免费 |
| 域名 | www.adlerian.com.cn | — | 已购买 |

**问题**：国内用户访问慢甚至打不开；`.com.cn` 域名无 ICP 备案，不能在国内合法运营。

## 二、为什么要迁到国内

1. **ICP 备案合规（核心）**：国内传播内容必须备案，备案要求服务器在国内（有 ISP 资质的接入商，如阿里云/腾讯云/华为云）。
2. **国内访问**：国外服务器慢/被墙，中文内容面向国内用户，影响致命。
3. 迁移不是因为省钱，而是合规 + 能访问。

## 三、服务器选型

| 项 | 选择 |
|---|---|
| 厂商 | 阿里云 或 腾讯云 |
| 产品 | **轻量应用服务器**（不要选 ECS，贵且没必要） |
| CPU | 2 核 |
| 内存 | 2G（省钱）/ 4G（更稳，推荐） |
| 系统盘 | 40G SSD |
| 带宽 | 3~5M（轻量默认自带） |
| 系统 | Ubuntu 22.04 LTS |
| 地域 | 华东/华北（离用户近） |
| 时长 | 新用户买 1 年（首年优惠） |

## 四、成本

| 阶段 | 月成本 |
|---|---|
| 首年（新用户优惠） | 约 5~8 元 |
| 之后（正常续费） | 约 50~80 元 |

- 数据库自托管（Docker PostgreSQL），0 额外。
- ICP 备案免费（流程 1~3 周）。
- 续费可趁 618/双11 活动。

## 五、承载能力

- 2核4G：100~300 并发，日活几千到上万（文字站很轻量）。
- 当前规模（几百~几千用户）：2核2G 都用不满。
- 升级时机：日活上万、或加图片流/实时聊天/全文搜索等重功能。

## 六、多站部署建议

- **推荐「一服务器多站」**：省钱、管理集中、共享 PostgreSQL + Nginx。
- 多站共用 1 个 PostgreSQL（建多个 database）+ 1 个 Nginx，每站只加一个后端容器（每个约 300~500MB 内存）。
- 2核4G 能带 2~3 个小站；4核8G 能带 5~8 个。
- 云服务器支持**不停机升配**，先 2核4G 起步，不够再扩到 4核8G。
- 某站流量做大后，再单独迁到独立服务器。

## 七、迁移待办清单

1. [ ] 买服务器：阿里云/腾讯云 轻量 2核4G（新用户首年）
2. [ ] 提交 ICP 备案（最耗时，1~3 周，尽早）
3. [ ] 配 Docker 环境 + 国内镜像源（Maven / Docker / apt）
4. [ ] 数据从 Supabase 迁到国内 PostgreSQL（用 database/init.sql）
5. [ ] 用 docker-compose.yml 部署（后端 + 数据库 + Nginx）
6. [ ] 域名解析到国内服务器
7. [ ] 备案通过后正式上线

## 八、注意事项（避坑）

- 国内服务器访问 GitHub / Docker Hub / Maven 中央仓库慢或不稳，必须配国内镜像源。
- 家庭宽带 + 公网 IP **不能备案**（接入商无资质 + 封 80/443 端口 + 可能 CGNAT），别折腾。
- 笔记本只能做本地开发机，做不了对外运营服务器。
- 后台发布文章权限：管理员邮箱 `xgh20005@163.com`（代码里 `app.admin-email` 默认值，可改环境变量 `ADMIN_EMAIL`）。
- 数据库迁移后需执行：`ALTER TABLE users ADD COLUMN IF NOT EXISTS email VARCHAR(320);`、`ALTER TABLE resources ADD COLUMN IF NOT EXISTS view_count INT DEFAULT 0;`。
