# 迁移到香港服务器 · 部署指南

> 目标：把前端 + 后端 + 数据库迁到一台香港 VPS，免 ICP 备案，延迟大幅降低。
> 认证（Supabase Auth）暂时保留，后续再单独迁移。

---

## 一、买香港 VPS

- 规格：**2 核 2G** 起步（几个用户完全够），系统选 **Ubuntu 22.04**。
- 成本：约 ¥30–60/月。
- 推荐厂商（任选其一）：
  - 腾讯云国际版 · 香港轻量应用服务器
  - Vultr · 香港
  - 阿里云国际版 · 香港
- 拿到：公网 IP + root 密码。

---

## 二、服务器初始化

```bash
# 登录服务器
ssh root@<你的IP>

# 安装 Docker + Docker Compose
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
```

---

## 三、拉代码 + 构建前端

```bash
# 安装 git + node（如果没装）
apt update && apt install -y git

# 拉代码
git clone https://github.com/xiaGuangHui1/adlerian-community.git
cd adlerian-community

# 构建前端（需要 Node 18+，服务器上装一次即可）
# 推荐在本地构建好 dist，再上传，避免服务器装 Node；这里给出本地构建方式：
#   cd frontend && npm install && npm run build
# 然后把 frontend/dist 上传到服务器的 adlerian-community/frontend/dist
```

> 简化建议：**前端在本地 `npm run build`，把 `frontend/dist/` 用 scp 传到服务器**，服务器不用装 Node。

## 四、配置环境变量

在项目根目录创建 `.env`：

```bash
DB_PASSWORD=请设置一个强密码
SUPABASE_URL=https://yipozzrnnzgpywgxamjm.supabase.co
SUPABASE_ANON_KEY=<你现有的 anon key>
SUPABASE_JWT_SECRET=<你现有的 JWT secret>
CORS_ORIGINS=https://www.adlerian.com.cn
```

> 这三个 Supabase 变量从 Railway 的 `adlerian` 服务变量里复制即可（认证暂时还用 Supabase）。

## 五、迁移数据库数据

从 Supabase 导出：

```bash
# 在本地（或服务器）执行，导出 public schema 的数据
pg_dump "postgresql://postgres:<Supabase密码>@db.yipozzrnnzgpywgxamjm.supabase.co:5432/postgres?sslmode=require" \
  --schema=public --no-owner --no-privileges > dump.sql
```

先启动数据库容器，再导入：

```bash
docker compose up -d db
sleep 10
docker compose exec -T db psql -U adlerian -d adlerian < dump.sql
```


## 七、域名解析

把 `www.adlerian.com.cn` 和 `adlerian.com.cn` 的 **A 记录**指向香港 VPS 的 IP。

（可选）用 Certbot 配 HTTPS：

```bash
apt install -y certbot
# 需要先把 nginx 80 端口跑起来，再用 certbot 自动配证书
```

## 八、注意事项

1. **认证暂用 Supabase Auth**：登录仍走 Supabase，只是数据库/后端/前端迁到了香港。
2. **数据库 SSL**：新的 `application-docker.yml` 用的是本地 PostgreSQL（无 SSL），比 Supabase 的 `sslmode=require` 更简单。
3. **数据导出范围**：只导 `public` schema（你的业务表），Supabase 自带的 `auth`/`storage` 等不需要。
4. **备份**：建议定期 `pg_dump` 备份，香港 VPS 磁盘小，注意别堆太多日志。
